1. Problem statement overview

Unplanned downtime in solar and wind farms can reduce energy generation and revenue. Manual inspection of a
large number of panels or turbines is slow, expensive, and may miss early signs of degradation. The proposed
system uses simulated IoT sensor data to detect anomalies and degradation before a serious failure occurs.

The main idea is simple: instead of waiting for an asset to fail, the system continuously watches its condition and
gives the operator an early warning.

3. Technologies used

Frontend — React + TypeScript: Operator/technician dashboards, charts, asset status, and alerts.
Backend — Flask + Python: REST APIs, business logic, authentication, and ML integration.
Database — PostgreSQL + SQL: Assets, sensor readings, predictions, alerts, and maintenance history.
AI/ML — Pandas + NumPy + PyTorch: Data preparation, feature engineering, anomaly detection, model training,
and risk scoring.
IoT — Sensor simulation / integration: Generate or receive vibration, temperature, current, soiling, and other
readings.
